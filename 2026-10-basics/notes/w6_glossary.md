## 一、形状记号怎么读

看到 `(3, 4)`，读作 **"3 行 4 列"**，不要读"三个四"。

看到 `(1, 2, 3, 3)`，读作 **"1 个批量，2 个头，3 个词，3 个词"**，从左到右逐层往里剥。

看到 `(3, 2, 2)`，读作 **"3 个词，2 个头，每头 2 维"**。

> 一条通用规律：形状里的每个数字，都对应一句人话。**读不出人话，就是还没懂。**

## 二、维度 / 尺寸符号

| 符号 | 中文全称 | 本段取值 | 干什么用 |
|---|---|---|---|
| `n` | 序列长度（sequence length），也叫 token 数 | 3 | 一句话里有多少个词/字 |
| `B` | 批量大小（batch size） | 1 | 一次同时喂几个样本 |
| `E` | 模型维度（embed_dim），**和 `d_model` 是同一个东西** | 4 | 每个词用几个数字来表示 |
| `d_model` | 模型维度，`E` 的另一个叫法 | 4 | 同上。Transformers 论文用 `d_model`，PyTorch 用 `embed_dim` |
| `h` | 头数（num_heads），也叫注意力头数 | 2 | 把 `E` 切成几份，并行算几种注意力 |
| `d_k` | 每头维度（head_dim），`K` 的维度 | 2 | `= E / h`，每个头用几维算相似度 |
| `d_v` | 每头 `V` 的维度 | 2 | 标准实现里取 `= d_k`，但**不是硬性要求** |
| `dk` | 代码里的变量名，就是 `d_k` | 2 | 同上，只是少了下划线 |

## 三、矩阵与投影

| 符号 | 中文全称 | 形状 | 干什么用 |
|---|---|---|---|
| `X` | 输入特征矩阵 | `(n, E)` | 一句话的原始表示 |
| `Q` | Query，查询向量 | `(n, d_k)` | **"我要找什么"** |
| `K` | Key，键向量 | `(n, d_k)` | **"我是什么"**（别人拿 Q 来跟它比） |
| `V` | Value，值向量 | `(n, d_v)` | **"我有什么可以给出去"** |
| `W_Q` | Q 的投影矩阵（weight for Query） | `(E, E)` 或 `(E, d_k)` | 把 `X` 变成 `Q` 的可学习矩阵 |
| `W_K` | K 的投影矩阵 | 同上 | 把 `X` 变成 `K` |
| `W_V` | V 的投影矩阵 | 同上 | 把 `X` 变成 `V` |
| `W_O` | 输出投影矩阵（output projection） | `(h·d_v, E)` | 把拼好的多头结果混合成最终输出 |
| `w_q` `w_k` `w_v` | 官方实现里 `W_Q/W_K/W_V` 的对应物 | `(E, E)` | **注意是 `(out, in)`，和你的方向相反** |
| `MHA` | Multi-Head Attention，多头注意力 | — | 本段主题：多个头并行算注意力再融合 |

> **`W_Q` 和 `w_q` 的区别（本段最大的坑）**
> - 你的实现：`Q = X @ W_Q`，所以 `W_Q` 是 **(in, out)** —— 行数是输入维
> - 官方实现：`Q = X @ w_q.T`，所以 `w_q` 是 **(out, in)** —— 行数是输出维（因为 `nn.Linear` 这么存）
> - 两者**形状都是 4×4**，数值互为转置。所以只能比数值，不能比形状。

## 四、PyTorch 函数（本段出现的全部）

| 函数 | 中文名 | 干什么 | 例子 |
|---|---|---|---|
| `view` | 重塑形状（reshape） | 不改数值，只改"怎么读这块内存" | `Q.view(3,2,2)` 把 4 列读成 2×2 |
| `reshape` | 同上，更通用的版本 | 内存不连续时 `view` 会报错，`reshape` 会自动复制 | 一般优先 `view` |
| `transpose` | 转置（交换两个维度） | `K.transpose(-2,-1)` 把 `(3,2)` 变 `(2,3)` | 为了能相乘 |
| `chunk` | 按维切片 | `t.chunk(3, dim=0)` 把第 0 维切成 3 等份 | 拆 `in_proj_weight` |
| `cat` | 拼接（concatenate） | 把多个张量沿某维接起来 | `torch.cat([a,b], dim=-1)` |
| `squeeze` | 挤维（去掉长度为 1 的维） | `(1,3,4).squeeze(0)` → `(3,4)` | 去掉批量维 |
| `unsqueeze` | 增维（插入长度为 1 的维） | `(3,4).unsqueeze(0)` → `(1,3,4)` | 加上批量维 |
| `softmax` | 归一化指数 | 把任意实数变成"和为 1 的概率" | `softmax(x, dim=-1)` 按行归一化 |
| `allclose` | 近似相等判断 | 逐元素比，允许极小误差 | `torch.allclose(a,b,atol=1e-6)` |

## 五、nn.MultiheadAttention 的构造参数

| 参数 | 中文名 | 本段取值 | 作用 |
|---|---|---|---|
| `embed_dim` | 模型维度 | 4 | 就是 `E` / `d_model` |
| `num_heads` | 头数 | 2 | 就是 `h` |
| `batch_first` | 批量维是否在最前 | `True` | `True` → 数据形状 `(批量, 词数, 维度)`；`False`（默认）→ `(词数, 批量, 维度)` |
| `bias` | 是否带偏置 | `False` | 带偏置会多出 `in_proj_bias`、`out_proj.bias`，对齐时多两个变量 |
| `dropout` | 随机失活比例 | `0.0` | 训练时随机把一部分数值置 0 防过拟合；**对齐时必须关掉**，否则每次跑结果不同 |

## 六、nn.MultiheadAttention 的内部属性

| 属性 | 中文全称 | 形状 | 说明 |
|---|---|---|---|
| `in_proj_weight` | 输入投影权重（input projection weight） | `(3E, E)` = `(12,4)` | **Q、K、V 三个投影矩阵纵向堆在一起**。`3E` 里 3 就是 Q/K/V 三个，与 `h` 无关 |
| `in_proj_bias` | 输入投影偏置 | `(3E,)` = `(12,)` | `bias=False` 时为 `None` |
| `out_proj` | 输出投影（一个 `nn.Linear` 子模块） | — | `out_proj.weight` 形状 `(E,E)`，就是 `W_O` |
| `out_proj.bias` | 输出投影偏置 | `(E,)` | `bias=False` 时为 `None` |
| `head_dim` | 每头维度（不是属性，是内部约定） | 2 | `= embed_dim // num_heads` |

## 十、三个容易混的"复杂度类"指标（10.27 补）

读论文 §4 和面试必考，**这三个不是一回事，混了就答错**。

| 指标 | 英文 | 衡量什么 | 决定什么 | 自注意力 / RNN |
|---|---|---|---|---|
| **每层计算复杂度** | complexity per layer | 要多少乘加运算、多少显存 | 需要几块卡、显存够不够 | `O(N²D)` / `O(ND²)` |
| **串行操作数** | sequential operations | 必须按顺序执行几步 | 能不能并行、GPU 利用率 | `O(1)` / `O(N)` |
| **最大路径长度** | maximum path length | 信号从前任一位置传到后任一位置要经过**几"跳"运算** | **梯度要连乘几次 → 长距离依赖好不好学** | `O(1)` / `O(N)` |

**最常错的是把"路径长度"说成"计算量"。**

```
路径长度 = 跳数，不是运算量。
自注意力：任意两位置直连 → 1 跳
RNN     ：沿时间步一个个走 → N 跳
```

**为什么跳数决定"好不好学"**：反向传播时梯度要沿这条路径逐跳连乘雅可比矩阵。
- N 跳 → 连乘 N 次 → 梯度衰减/爆炸（RNN 的经典病）
- 1 跳 → 只乘 1 次 → 梯度几乎无损传回

> **面试话术**：问"Transformer 凭什么比 RNN 强"，**不要说"复杂度低"** —— 会被反问"N<4D 时 FFN 才是大头"。正确答案是**最大路径长度从 `O(N)` 降到 `O(1)`，梯度传播距离恒定**，长距离依赖和近距一样好学；附带收益是串行操作数降到 `O(1)`，可以完全并行。

## 十一、论文 §3—5 高频数字（10.27 补，可背）

| 项 | 值 |
|---|---|
| base：N / `d_model` / `h` / `d_k=d_v` / `d_ff` / 参数 | 6 / 512 / 8 / **64** / 2048 / **65M** |
| big：N / `d_model` / `h` / `d_k=d_v` / `d_ff` / 参数 | 6 / 1024 / 16 / **64** / 4096 / **213M** |
| 优化器 | Adam，`β1=0.9`、`β2=0.98`（**非常规的 0.999**）、`ε=1e-9` |
| `warmup_steps` | **4000** |
| dropout（残差）/ label smoothing | **0.1** / **0.1**（big 的 dropout 是 0.3） |
| 位置编码波长范围 | `2π ≈ 6.28` 到 `10000·2π ≈ 62832`（等比） |
| 训练成本 | 8×P100，base 12h / 100k 步，big 3.5 天 / 300k 步 |

三个"为什么"：
- **`β2=0.98`**：二阶矩窗口更短，对训练初期梯度尺度剧变更敏感 → 更稳
- **`warmup=4000`**：训练初期梯度方向不可靠，先小学习率探路
- **嵌入 ×`√d_model`**（base 是 ×**22.6**）：正弦位置编码值域是 `[-1,1]`，词嵌入不放大就会被位置信息淹没
