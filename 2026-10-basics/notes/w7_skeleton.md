# W7 一页骨架：六站流水线

**全文只有一句话：把一段文本变成 loss，再按 loss 改参数。中间只有六站。**

以后不再用"第 X 段"这种编号（已废弃），统一说"第 k 站"。

---

## 六站总表

| 站 | 干什么 | 输入 | 输出 | 关键文件 |
|---|---|---|---|---|
| ① 切分 | 文本 → 整数 id | `"我们先"` | `(B, T)` | `w7_corpus.py` / `w7_tokenizer.py` |
| ② 查表 | 整数 → 向量，并加位置 | `(B, T)` | `(B, T, 64)` | `w7_model.py` 的 `token_emb` + `pos_emb` |
| ③ 混合 | 字与字交换信息（attention + FFN） | `(B, T, 64)` | `(B, T, 64)` **形状不变** | `w7_block.py` / `w7_gpt.py` |
| ④ 打分 | 每个位置给 1220 个字各打一分 | `(B, T, 64)` | `(B, T, 1220)` | `w7_model.py` 的 `lm_head`（与 ② 共享权重） |
| ⑤ 对答案 | 和"右移一格"的答案比 | `(B, T, 1220)` + `(B, T)` | **一个标量** | `w7_model.py` 的 `lm_loss` |
| ⑥ 更新 | 按梯度改参数，回到 ② | 标量 | 新参数 | 待写（第 5 段） |

**看这张表只要注意一件事：只有 ③ 的输出形状和输入一样。** 其余每一站形状都在变。
③ 不变是硬要求 —— 因为有残差 `x = x + 子层(x)`，形状不一样根本加不上。

---

## 一条规则顶六站：B 和 T 从头到尾不动

前两维 `(B, T)` 一辈子不变，**每一站只改最后一维**：

```
(文本)  →  (B, T)  →  (B, T, 64)  →  (B, T, 64)  →  (B, T, 1220)  →  一个数
   ①            ②              ③              ④               ⑤
                 最后一维：无 → 64 → 64 → 1220 → 消失
```

所以任何一站的形状都不用背，**从上一站推**：

- ③ 进 `(B,T,64)`，因为要加残差，所以出也是 `(B,T,64)`
- ④ 要把"一个 64 维向量"变成"1220 个分数"，所以出 `(B,T,1220)`
- ⑤ 把 `(B,T,1220)` 和 `(B,T)` 逐个位置对答案，所有位置一起平均，所以出**一个数**

**这条规则是 W7 唯一需要记的结构。** 其余都是它的推论。

## 全 W7 只需记住的 5 个数字

| 数字 | 是什么 | 用在哪 |
|---|---|---|
| **1220** | 词表大小 V（字符级） | ④ 的输出末维、⑤ 的 ln(V) |
| **64** | d_model，每个字的向量维数 | ②③④ 的中间维 |
| **7.1066** | ln(1220)，随机初始化时的 loss | ⑤ 的自检基准 |
| **181,120** | 2 层模型的参数量 | 判断模型大小 |
| **0.00082** | 1/1220，初始化时每个字的概率 | 理解 7.1066 从哪来 |

其余所有数字（12,288 / 49,408 / 98,816 / 82,304 / 0.0066 / cos 表 …）都是**推导过程**，用的时候再查，不用记。

## 每一站只问三个问题

1. **进这一站时，张量什么形状？**
2. **这一站对它做了什么？（一句话，不许用术语）**
3. **出这一站时，张量什么形状？**

三问答全 = 这一站过了。答不出 = 没懂，不要往下走。

---

## 各站"一句话版"（面试口述用）

- **①** 文本切成子词再映射成整数，词表 1220。
- **②** 每个整数查一行向量，再加一行位置向量 —— 因为 attention 本身不知道顺序。
- **③** 字与字通过 attention 交换信息，再过 FFN 做逐字变换，形状始终是 (B,T,64)。
- **④** 用一个和 ② 共享的矩阵给 1220 个字打分。
- **⑤** 和右移一格的答案算交叉熵，一次前向得 2048 个预测。
- **⑥** 反传得梯度，优化器改参数，重复。
