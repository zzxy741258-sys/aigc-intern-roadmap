## 1. 一句话先给你骨架（读完回来对）

> 这篇论文的贡献不是"发明了注意力"，而是**证明了只靠注意力（不用 RNN、不用 CNN）就能做序列转换**，并且靠「多头 + 残差 + 位置编码 + 平方根缩放」这四件套让它训得起来。

**"训得起来"是关键词。** 论文里每个设计选择，本质上都在解决同一个问题：**深层堆叠下的梯度稳定性。**

| 设计           | 直接解决什么           |
| ------------ | ---------------- |
| 残差连接         | 梯度能直达浅层          |
| LayerNorm    | 每层输入尺度一致         |
| √d_k 缩放      | softmax 不进入梯度饱和区 |
| warmup       | 训练初期不发散          |
| 嵌入 ×√d_model | 词向量和位置编码尺度对齐     |

**这五条串起来，就是"Transformer 为什么能训到 6 层、后来能训到 96 层"的完整答案。**

## 2. §3 模型架构

### 2.1 编码器 / 解码器堆叠（§3.1）

- 编码器：`N=6` 个相同层，每层 **2 个子层** —— 多头自注意力 + 逐位置前馈网络（FFN）
- 解码器：`N=6` 个相同层，每层 **3 个子层** —— 带 mask 的自注意力 + 交叉注意力 + FFN
- 每个子层外面套：`LayerNorm(x + Sublayer(x))`
- 所有子层、嵌入层输出维度统一为 `d_model=512`（这是残差能相加的前提）

### 2.2 三种注意力的 Q/K/V 从哪来（**这是"能画出形状"那条验收的核心**）

| 位置              | Q 来自         | K、V 来自      | 有没有 mask        | 作用        |
| --------------- | ------------ | ----------- | --------------- | --------- |
| 编码器自注意力         | 上一层编码器输出     | 同左          | ❌ 无             | 让每个源词看到全句 |
| 解码器自注意力（masked） | 上一层解码器输出     | 同左          | ✅ **有**（causal） | 防止看到未来词   |
| 编码器-解码器交叉注意力    | **上一层解码器输出** | **编码器最终输出** | ❌ 无             | 解码时对准源句   |

**记忆口诀：Q 永远来自"当前正在处理的那一侧"，K/V 来自"被查阅的那一侧"。**

自注意力的 Q/K/V 同源 → Q、K、V 只是同一批词用三套不同权重投影出来的。  
交叉注意力的 Q 在解码器、K/V 在编码器 → 这就是"翻译时看原文"的位置。

### 2.3 §3.2.1 缩放点积注意力（**必读**）

公式（你 W6 已经手写过）：

```
Attention(Q, K, V) = softmax( QKᵀ / √d_k ) · V
```

**为什么除以 √d_k —— 论文脚注 4 的原话论证：**

> 假设 q 和 k 的各分量是**独立**的随机变量，均值 0、方差 1。则点积 `q·k = Σᵢ qᵢkᵢ` 的均值是 0、**方差是 d_k**。

也就是说：**d_k 越大，点积的标准差 ≈ √d_k，数值越容易跑到 ±几十。**

后果链条（面试要这么说）：

```
d_k 大 → 点积方差 = d_k，幅值 ~ √d_k
       → softmax 的输入差得很开
       → softmax 输出接近 one-hot（几乎全压在最大项）
       → 该位置的梯度 ≈ 0（饱和）
       → 参数学不动
```

除以 √d_k 恰好把方差从 d_k 拉回 **1**，softmax 工作在梯度健康的区间。

**具体数字**：`d_k=64` 时，未缩放的点积标准差 ≈ 8；缩放后 ≈ 1。差 8 倍。

> 注意这跟你 W6 算的 `√2 vs √4` 是同一件事的两个方向：那次是**过度缩放**（压缩了注意力分布的尖锐度），这里是**不缩放**（分布过于尖锐、梯度消失）。**两头都坏，√d_k 是让方差回到 1。**

**论文为什么选点积而不是加性注意力（additive attention）？**

- 加性注意力（Bahdanau 那套）用一个小前馈网络算分数
- 点积注意力可以直接用**高度优化的矩阵乘**，**更快、更省显存**
- 论文实测：`d_k` 小的时候两者效果相当；`d_k` 大时点积优势明显
- 所以选点积 + 缩放

### 2.4 §3.2.2 多头注意力（扫读，但数字要记）

论文原话：`h = 8`，`d_model = 512`，所以

```
d_k = d_v = d_model / h = 512 / 8 = 64
```

**论文的关键声明**：

> "Due to the reduced dimension of each head, the total computational cost is similar to that of single-head attention with full dimensionality."  
> （因为每个头维度降低了，总计算量与"全维度的单头注意力"相当。）

**把这句话算清楚**（面试会追问"为什么相当"）：

|         | 单头（h=1, d=512） | 多头（h=8, d_k=64）               |
| ------- | -------------- | ----------------------------- |
| QKᵀ 计算量 | `2·n²·512`     | 每头 `2·n²·64`，8 头合计 `2·n²·512` |
| 与 V 相乘  | `2·n²·512`     | 每头 `2·n²·64`，8 头合计 `2·n²·512` |
| **总计**  | **`4n²·512`**  | **`4n²·512`**                 |

**完全相等。** 多头不是"多算 8 倍"，是"把同样的算力切成 8 份并行用"。这跟 W6 讲的"参数总量不变"是同一件事的两面。

### 2.5 §3.3 位置编码（**必读**）

公式：

```
PE(pos, 2i)   = sin( pos / 10000^(2i/d_model) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )
```

**逐符号：**

| 符号             | 含义             | 取值                                 |
| -------------- | -------------- | ---------------------------------- |
| `pos`          | 位置序号           | 0, 1, 2, …                         |
| `i`            | 维度对的编号         | 0 到 `d_model/2 - 1`                |
| `2i / d_model` | 归一化维度          | **这是注意力的关键**：`2i/d_model ∈ [0, 1)` |
| `10000`        | 频率基数           | 固定常数，和 RoPE 里的 base 是同一个角色         |
| 偶/奇维           | 用 sin / cos 交替 | 这样写成二维旋转更自然                        |

**论文自己点明的性质：波长构成等比数列，从 `2π` 到 `10000·2π`。**

代入 `d_model=512` 算一下：

```
i = 0    → 10000^0 = 1      → 波长 = 2π ≈ 6.28
i = 255  → 10000^(510/512) ≈ 9962  → 波长 ≈ 10000·2π ≈ 62832
```

**最短波长 6.28 个位置、最长 62832 个位置，等比递增。** 短波长管"相邻几个词"的精细位置，长波长管"隔了几百个词"的粗粒度位置 —— 多尺度分工。

**为什么用正弦而不是可学习位置向量？论文给了两条理由：**

1. **可外推到比训练时更长的序列**（虽然这个外推能力实际很有限，见第 5 节）
2. **`PE(pos+k)` 可以写成 `PE(pos)` 的线性变换** —— 因为 sin/cos 的角和公式，相对位置信息内蕴在编码里

论文诚实地写了：**他们也试了可学习的位置嵌入，结果几乎一样**（Table 3 row E），但选了正弦版因为"可能"能外推。

### 2.6 §3.4、§3.5 嵌入与输出层（扫读，但一个数字必须记）

- 输入嵌入、输出嵌入、softmax 前的那层线性变换**共享同一个权重矩阵**
- **嵌入要乘 `√d_model`**

**为什么乘 √d_model？** 因为位置编码的值域是 `[-1, 1]`，如果词嵌入也是 `~N(0,1)` 量级，加进去以后**位置信息会被淹没**；反过来又不该让位置信息主导。乘 `√512 ≈ 22.6` 把嵌入的尺度抬到与位置编码可比的范围。

> 这也是为什么后来 RoPE 能取代它：**RoPE 不做加法，用旋转把位置刻进方向，从根上消除了"两个信号尺度要对齐"这个麻烦。**

## 3. §4 Why Self-Attention（**已读过，只补 Table 1**）

W6 补讲的复杂度已经覆盖了这部分。**只需把论文 Table 1 记住这几行：**

| 层类型      | 每层复杂度       | 串行操作数    | 最大路径长度       |
| -------- | ----------- | -------- | ------------ |
| **自注意力** | `O(n²·d)`   | **O(1)** | **O(1)**     |
| 循环（RNN）  | `O(n·d²)`   | O(n)     | O(n)         |
| 卷积（CNN）  | `O(k·n·d²)` | O(1)     | `O(log_k n)` |
| 受限自注意力   | `O(r·n·d)`  | O(1)     | `O(n/r)`     |

**"最大路径长度"是这个表里最有价值的指标**，面试常问"为什么 Transformer 比 RNN 更容易学长距离依赖"：

- 路径长度 = **信号从前任一位置传到后任一位置，要经过多少次运算**
- RNN：要走 n 步 → 梯度连乘 n 次 → **梯度消失/爆炸**
- 自注意力：**一步到位**，任意两个位置直连 → 路径恒为 1
- 后果：**梯度传播路径短 → 长距离依赖容易学；串行操作 O(1) → 能完全并行**

**这三列对应三个不同的工程问题，别混：**

- 复杂度 → 算力和显存
- 串行操作数 → **能不能并行、GPU 利用率**
- 最大路径长度 → **长距离依赖好不好学**

## 4. §5 Training（**必读，全是可背的数字**）

### 4.1 §5.2 优化器与学习率

| 参数             | 值                     |
| -------------- | --------------------- |
| 优化器            | Adam                  |
| `β1`           | **0.9**               |
| `β2`           | **0.98**（不是默认的 0.999） |
| `ε`            | **1e-9**              |
| `warmup_steps` | **4000**              |

学习率公式（论文原式）：

```
lrate = d_model^(-0.5) · min( step^(-0.5),  step · warmup_steps^(-1.5) )
```

**分两段理解（这是"warmup 到底在干嘛"的标准答案）：**

| 阶段            | 取到哪一项                     | 学习率行为            |
| ------------- | ------------------------- | ---------------- |
| `step < 4000` | 右边 `step · warmup^(-1.5)` | **线性上升**         |
| `step > 4000` | 左边 `step^(-0.5)`          | **按 1/√step 衰减** |

代入 `d_model=512`：`512^(-0.5) = 1/22.6 ≈ 0.0442`。所以峰值学习率约 `0.0442 · (1/√4000) = 0.0442 · 0.0158 ≈ 0.0007`。

> **`β2=0.98` 而不是 0.999，这是个有意义的偏离。** 二阶矩的滑动平均窗口更短，对梯度尺度的变化反应更快 —— 在训练初期梯度尺度剧烈变化时更稳。面试问"你调过 Adam 吗"，答这一条比答"调过学习率"高一档。

**为什么需要 warmup？** 训练初期参数随机，梯度方向不可靠；此时用大学习率会把参数推到坏区域。**先用小学习率"探路"，等梯度统计稳定后再放大。** 深层 post-LN 结构对这一点尤其敏感（见第 5 节）。

### 4.2 §5.3 正则化

| 手段              | 值                                | 加在哪                |
| --------------- | -------------------------------- | ------------------ |
| Dropout（残差）     | `P_drop = 0.1`（base）/ `0.3`（big） | 每个子层输出，**在加到残差之前** |
| Label smoothing | `ε_ls = 0.1`                     | 标签分布               |

**Label smoothing 的效果（论文 Table 3 有）**：**perplexity 变差，但 BLEU 和准确率变好。**

这个"反向"现象面试很爱问，答案：**困惑度奖励"预测得自信"，label smoothing 故意让模型别太自信；而泛化（BLEU）恰恰受益于"别过度自信"。** 指标和目标是两件事。

### 4.3 §5.1 模型配置（背这两列就够）

|             | base     | big  |
| ----------- | -------- | ---- |
| 层数 N        | 6        | 6    |
| `d_model`   | **512**  | 1024 |
| `h`         | **8**    | 16   |
| `d_k = d_v` | **64**   | 64   |
| `d_ff`      | **2048** | 4096 |

## 5. 论文里"已经过时"的 5 个点（**面试加分项**）

读完论文最大的陷阱：**把 2017 年的做法当成现在的标准答案。** 下面 5 条都是论文写了、但业界已经改了的。

| # | 论文 2017                                            | 现在主流                                     | 为什么改                                                                                           |
| - | -------------------------------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 1 | `LayerNorm(x + Sublayer(x))`（**post-LN**，归一化在残差之后） | `x + Sublayer(LayerNorm(x))`（**pre-LN**） | post-LN 在深层时梯度对初始化极敏感，**必须靠 warmup 才能训**；pre-LN 把归一化放到子层入口，残差路径上是纯恒等映射，梯度直通，**不用 warmup 也能训深** |
| 2 | 正弦**绝对**位置编码（加到嵌入上）                                | **RoPE**（旋转位置编码，LLaMA 系）                 | 加法编码在长上下文外推时失效；RoPE 让内积只依赖位置差，天然相对                                                             |
| 3 | FFN 用 **ReLU**                                     | **GELU** / **SwiGLU**                    | GELU 更平滑；SwiGLU 门控结构用 `2/3` 的 `d_ff` 达到同等效果，**省参数**                                            |
| 4 | **LayerNorm**                                      | **RMSNorm**（LLaMA 系）                     | 去掉均值中心化，只保留方差归一化，**快约 7—15%，效果不掉**                                                             |
| 5 | **Encoder-Decoder**（为翻译设计）                         | **Decoder-only**（GPT 系）                  | 统一成一个自回归模型，一份参数做所有任务；交叉注意力那套结构在通用大模型里被放弃                                                       |

**最该记住的是第 1 条。** 面试问"Transformer 为什么难训"，标准答案就是：**原版 post-LN + 深层 → 必须 warmup**；现在用 pre-LN 解决了这个问题。**能说出这一条，说明你读的是论文而不是博客。**
